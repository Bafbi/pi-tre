1. The problem (baseline)

Two extensions spawned headless pi subagents with copies of the same process plumbing. Every fix landed twice and drifted.

repo-query — runExplorersillajje — sub-generator.ts
Runschild pi process, tools enabled, long explorationchild pi -p --no-session --no-tools, text only
Timeout300 s, SIGTERM → SIGKILL escalation with a grace periodplain kill(), no escalation
Abortexternal AbortSignal with listener cleanup; partial answer keptnone
Streaminganswer and thinking streamed live during explorationnone
Usageaccumulated and mapped into AgentToolResult.usageignored
Protocolhand-parsed pi JSON-lineshand-parsed pi JSON-lines (duplicate)

The concrete costs: a fix to the kill/escalation path, the abort cleanup, or the event parser had to be made in two places; the JSON-lines coupling was maintained twice; and sillajje's cruder lifecycle could hang without escalation.

2. Context and constraints

  • Isolation vs latency. repo-query explores unknown repos — long, tool-heavy, untrusted work that needs hard isolation and SIGKILL. sillajje's stamping calls are short, tool-free text generations retried up to maxAttempts, where spawn latency is paid on every attempt.
  • Policy stays per extension. Retries and fallbacks belong to sillajje; streaming, the partial-answer-on-abort notice, and usage mapping belong to repo-query. The shared layer must not absorb either.
  • Existing seams must survive. repo-query's factory overrides and sillajje's SpawnFn are the test seams; the migration must keep their suites green without new harnesses.
  • Dependency floor. The package stays dependency-free apart from node:child_process, with pi-coding-agent and the pi-ai/pi-agent-core types as peer dependencies.
  • Protocol coupling is a liability. The process backend parses pi's JSON-lines protocol, which is coupled to the installed pi version. It needs a tripwire.

3. Decision

One contract, two backends; the backend is chosen per call site, never auto-detected. The package @pi-tre/pi-subagent exposes runSubagent(task, backend?) returning a SubagentSession with an event stream, usage(), and abort(). The only new seam is SubagentBackend.

  • Process backend (createProcessBackend) — repo-query's proven child-process lifecycle, ported with its timeout, SIGTERM→SIGKILL escalation, abort, exit semantics, byte cap, and JSON-lines parser.
  • In-process backend (createInProcessBackend) — wraps the pi SDK's createAgentSession; fresh in-memory session per call, tools allowlist and excludeTools recursion guard, parent model/thinking inheritance hooks, cooperative abort, wall-clock deadline.

This is recorded in docs/adr/0001-subagent-isolation.md. The alternatives were rejected: process everywhere (spawn latency multiplies across sillajje's retries), in-process everywhere (cooperative abort fails on hung exploration), and auto-detection (a heuristic where the trade-off should be deliberate).

Consumer adoption

  • repo-query runs exploration over the process backend. Inline spawn, parsing, and usage accumulation were deleted: explorer.ts shrank 541 → 276 lines. Prompt building, live streaming, partial-answer-on-abort, truncation, and usage mapping stayed. ExplorerProcess/SpawnFunction survive as re-exports so the abort suite compiles unchanged.
  • sillajje points its SpawnFn adapter at the in-process backend. The retry wrapper, fallback values, and fellBack flag are byte-for-byte unchanged; a timedOut exit maps to the same non-zero code + stderr the old timeout rejection produced. Prompts, deriveSubject, and generation output are unchanged.

Monorepo, docs, and the protocol tripwire

  • packages/* added to the pnpm workspace, mise config_roots, and tsconfig, so the package gets the same lint/typecheck/test/check tasks.
  • test/fixtures/pi-session.jsonl records and scrubs a real pi session; a replay test pins the parser's event shapes, and a meta file pins the fixture to pi 0.84.4. A version bump fails the test until the fixture is regenerated deliberately.
  • Package README documents the contract and both backends; ADR-0001 records isolation; sillajje's ADR-0002 carries a supersession note for the transport change.
