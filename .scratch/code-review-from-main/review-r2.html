Spec

Spec: .scratch/sillajje-diff-budget/diff-budgeting.html ("Recommended shape" and "Open questions"). ADR 0003 is the accepted decision record and deliberately deviates on some points; those are recorded as deviations, not defects.

1. Trailing collapse line escapes the token ceiling (implemented slightly wrong)

Spec: "Track budget in bytes or estimated tokens (chars / 4), never in lines alone". ADR 0003: "The budget counts markers too". diff.ts:265-269 appends ... and N more files omitted without charging tokens. Bounded and small, but it is the one line in the assembled diff the budget does not cover.

2. Status wording overstates when markers collapse (implemented slightly wrong, minor)

Spec: "Emit one status when content was dropped, for example info code diff-condensed with the count of omitted files." emitDiffCondensed prints "N files kept by name only" and lists up to five paths. When dropped > 0, some of those files were collapsed into the trailing line and are not present by name in the diff text, so "kept by name only" is not accurate for them. The count itself is present, which is what the spec asked for.

3. Default omit list differs from the spec's example (documented deviation)

The spec's example list is ["pnpm-lock.yaml", "*.lock", "*.min.js", "dist/**", "*.snap"]. The shipped default (config.ts:181-194) covers lockfiles, minified output, source maps, *.generated.*, *.pb.go, and vendored trees, but not dist/** or *.snap. The spec left the default list as an open question and ADR 0003 scopes it to "machine-generated manifests, minified output, source maps, and vendored code", so this is a deliberate scope choice; record only.

4. Marker shows a total, not the added/removed split (documented deviation, minor)

The spec's example marker is Modified regular file … (+1834/-902):. The shipped marker is Modified big.ts (900 lines changed): diff content omitted (too large). The spec's requirement text says "change count", so the total is defensible; the split was illustrative.

5. Transcript budget still open (open question)

Spec Option D caps the transcript with the same machinery. ADR 0003: "The transcript is not budgeted yet." Open question, not a requirement.

6. A prior review report is committed (scope creep, weak)

.scratch/code-review-from-main/review.html is a process artifact from the earlier review, unrelated to the diff-budget feature. The repo's issue tracker lives under .scratch/, so it is consistent with local convention, but it is not part of the spec.

Implemented as asked

  • All three fetch sites share one budget: interaction, diff-only, and fold call collectDiff.
  • The {{diff}} substitution is untouched; condensing is an input transform.
  • The diff-condensed info status carries the omitted count.
  • The whole-diff bound is estimated tokens (chars / 4), not lines alone.
  • Option B boundary: Jj.diffFiles plus filesets on Jj.diff; a file over the line gate is never read.
  • Option C: a default omit list ships and keeps name and count as one-line markers.
