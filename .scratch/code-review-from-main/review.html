Code review: diff budget, from main

One defect reaches both axes: the whole-diff fast path skips the token ceiling, so the budget does not bound what it claims to bound.

2026-10-05 scope: sillajje-core, sillajje-jj, sillajje adapter fixed point: main
Summary Standards Spec Verification

Summary

Diff under review: heads(::@ & ::main)..@, three commits, 25 files, ~1,246 insertions. The spec is .scratch/sillajje-diff-budget/diff-budgeting.html, with the accepted decision in packages/sillajje-core/docs/adr/0003-diff-budget.md.

Both axes point at the same line from different directions. Spec says "track budget in bytes or estimated tokens, never in lines alone"; Standards says the glossary term "Diff budget" promises a whole-diff token ceiling. collectDiff returns the whole diff unmeasured on the line-gate fast path, so neither promise holds.

Standards

Sources: root AGENTS.md, docs/agents/domain.md, the per-package CONTEXT.md glossaries, the ADR format, plus the smell baseline. Tooling enforces the rest (see Verification).

1. Documentation states a guarantee the code breaks (documented standard)

packages/sillajje-core/CONTEXT.md defines Diff budget as "a per-file line gate and a whole-diff estimated-token ceiling." ADR 0003 line 19 repeats that the estimate "bounds a prompt." On the fast path (diff.ts:146-148) the whole diff is returned with no token measurement, so a diff under the line gate can exceed the stated ceiling by orders of magnitude. The glossary is the project's own contract; it currently overstates the code.

2. Duplicated Code (judgement)

The same three-step shape repeats at three call sites: collect, assign diff, emit.

const collected = await collectDiff(jj, spec, cfg.diff, cwd);
diff = collected.text;
emitDiffCondensed(onStatus, collected.omitted);

Seen at stamp/interaction.ts:67, stamp/diff-only.ts:50, and fold.ts:663. A wrapper in diff.ts that emits and returns the text would leave one shape. Judgement call: the three sites differ in error policy, so the wrapper can't swallow the try/catch, only the emit step.

3. Mysterious Name (judgement, minor)

gate(file, budget, spent) returns an OmitReason for skipping a file; the name says nothing about omission. omitReason names what it returns. Same for the local reason.

4. New test-naming convention (judgement, minor)

packages/sillajje-jj/test/diff-real.test.ts is the only *-real.test.ts in the tree. The sibling real-jj tests are mutations.test.ts, transaction.test.ts, versions.test.ts. The -real suffix introduces a convention the repo does not use. Not a hard violation; the file's content follows the real-jj harness pattern correctly.

5. Speculative export (judgement, weak)

DiffOptions went from internal to exported and re-exported from sillajje-jj/src/index.ts. No consumer in this diff imports it; core imports DiffSpec. It is harmless (public-signature completeness), but nothing asked for it.

Spec

Spec: .scratch/sillajje-diff-budget/diff-budgeting.html ("Recommended shape" and "Open questions"). ADR 0003 is the accepted decision record and deliberately deviates on some points; those are noted as deviations, not defects.

1. Token ceiling bypassed on the fast path (requirement implemented wrong)

Spec: "Track budget in bytes or estimated tokens (chars / 4), never in lines alone: a line of minified JS is not a line of source."

diff.ts:146 returns fetchText(...) whenever totals.added + totals.removed <= budget.maxLinesPerFile, with no estimateTokens check and an empty omitted array. A 2 MB single-line bundle is 1–2 changed lines, so it is inlined whole. This is the exact failure mode the spec's "Why it bites" section names. The fast path needs to measure its own text and fall through to the per-file walk when it exceeds maxTokens.

2. Configurable skip list missing (requirement missing)

Spec: Option C, "a configurable skip list … Omit them regardless of size," and "C is orthogonal and should ship with either." The recommended shape names omit: ["pnpm-lock.yaml", …]. The shipped schema exposes only maxTokens and maxLinesPerFile (config.ts:188-198, schema JSON). ADR 0003 rejects a shipped default list "for now," which is a fair call, but the spec asked for a knob, and no knob exists.

3. diff-condensed status lacks the count (partial)

Spec: "Emit one status when content was dropped, for example info code diff-condensed with the count of omitted files." emitDiffCondensed prints up to five paths plus +N more; there is no numeric total when there are five or fewer. Add the count.

4. Budget defaults differ (documented deviation, not a defect)

Spec proposed maxBytes: 200_000 and maxFileBytes: 20_000; the ship uses maxTokens: 12_000 and maxLinesPerFile: 400. The spec left the unit and the number as open questions and ADR 0003 resolves them, so record only.

5. Transcript budget not done (open question)

Spec Option D caps the transcript too. ADR 0003 states "the transcript is not budgeted yet." Open question, not a requirement.

Implemented as asked

  • Option B boundary: Jj.diffStat, Jj.diffFiles, and filesets on Jj.diff; the big file is never read on the per-file path.
  • Per-file line gate drops content before fetch, keeping path and change count in the marker.
  • All three fetch sites share one budget; {{diff}} substitution untouched.
  • New sillajje-core module with unit tests, plus a real-jj pairing test.

Test-coverage gap (spec-adjacent)

diff-real.test.ts covers add, modify, and remove. The binary and zero-delta rows that decodeDiffStatCounts special-cases are only unit-tested with hand-written fixtures. I reproduced empty-file and pure-rename rows against jj 0.44 and the --summary/--stat arrays paired, so the pairing holds; the real-jj test just does not pin it.
